1. Open the Web Terminal (or File Manager) of this app and set `NEXTCLOUD_HOST` in `/app/data/env.sh`
   to the host name of your Nextcloud, then restart the app.
2. In Nextcloud: Administration settings → Office → "Use your own server" → `$CLOUDRON-APP-ORIGIN`.
3. Open an `.xlsx` or `.docx` in Nextcloud Files.
