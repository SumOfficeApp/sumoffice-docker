# Owner submission — OVHcloud Marketplace

Package: `cloud-init.yaml` plus the shared `../vm/` installer and released-image compose.

OVHcloud does not expose a self-service application-upload button for this package shape. The owner must email
`vendeur-marketplace@ovhcloud.com`, ask to onboard SumOffice as an amd64 Ubuntu 24.04 image, and attach the listing
text and technical description from `README.md`. When OVHcloud assigns a technical contact, provide this cloud-init
and follow their requested image/import format.

Approve publication only after their staging instance passes `/healthcheck`, the signed command doctor, DOCX save,
and XLSX save. There is no PPTX claim.
