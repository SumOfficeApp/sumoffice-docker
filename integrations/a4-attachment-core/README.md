# Общий контракт вложения для российских каналов

Этот маленький модуль ограничивает форматы `xlsx`, `xlsm`, `docx`, `pptx` и
передаёт Blob в серверный обработчик организации. Обработчик обязан:

1. проверить вошедшего пользователя средствами хозяина;
2. создать ограниченный по времени сеанс Сервера A4;
3. вернуть `{ "id": "…", "editorUrl": "https://…" }`;
4. после сохранения вернуть изменённый Blob только тому же пользователю.

В браузерный код нельзя помещать JWT, ключ приложения или общий секрет. Поэтому
`endpoint` — это backend конкретного дополнения, а не открытая загрузка файла.
