# Сервер A4 для Directum RX

Точка входа — штатная служба `/collaboration`: Directum RX уже умеет передавать
документ редактору, принимать сохранение и создавать новую версию. Поэтому
чужой модуль и чужие JAR не нужны; меняются только адрес, порт и общий JWT.

`settings.example.json` — нейтральное представление обязательных значений для
администратора. Оно не предназначено для слепого копирования в базу: точное
место настройки зависит от выпуска RX. `validate-settings.mjs` проверяет четыре
формата, HTTPS, `/collaboration` и то, что секрет задан переменной среды.

Живой круг требует Directum RX 4.10+ с правами администратора. Его выполняет
владелец стенда; этот комплект не заявляет круг пройденным.
