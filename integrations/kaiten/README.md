# A4 Office для Kaiten

Точка входа — кнопка дополнения в карточке. Дополнение получает файлы через
`getCardProperties("files")`, показывает только XLSX/XLSM/DOCX/PPTX и открывает
полноэкранный iframe. Для файлов ограниченного доступа код каждый раз получает
свежую подписанную ссылку; токен Kaiten не передаётся по этой ссылке.

Возврат сначала загружает новую версию через
`POST /api/v1/cards/{card_uid}/files`, затем удаляет прежнее вложение. Такой
порядок не теряет исходник при отказе загрузки. Живой круг требует учётку
разработчика дополнений и тестовую компанию с Restricted file access.
