# A4 Office для Мегаплана

Точка входа — приложение-виджет в карточке задачи или сделки. Backend сначала
проверяет `userSign` именно на домене аккаунта через
`/BumsSettingsApiV01/Application/checkUserSign.json`, после чего может открыть
сеанс организации. Изменённый файл загружается через `/api/file`; полученный
идентификатор прикрепляется к задаче/сделке её API v3.

В репозитории нет ключа приложения: он остаётся только на backend. Конкретную
модель задачи/сделки и поле вложений нужно подтвердить в тестовом аккаунте,
потому здесь загрузка доказана unit-тестом, а привязка сущности не заявлена.
