Edit Excel and Word attachments without leaving Odoo

.xlsx, .xlsm, .xlsb and .docx open in SumOffice; Ctrl+S saves back into the attachment

Macros travel with the file. Excel and Word open the result without a repair dialog. The file stays in Odoo; every edit runs with the rights of the person who opened it.

  • An Open in SumOffice button on office attachments in the chatter
  • WOPI host inside Odoo: CheckFileInfo, GetFile, PutFile, locks
  • Signed access tokens and verified WOPI proof keys

Requires a SumOffice server: github.com/SumOfficeApp/sumoffice-docker
